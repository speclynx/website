Get started with SpecLynx

Validate your first API spec in under five minutes. One command, no account, nothing to configure.

1. Validate your first spec

Run the CLI against any OpenAPI, AsyncAPI, Arazzo, or Overlay document, a local file or a URL. You need Node.js 20 or newer; npx fetches the CLI on first use, so there is nothing to install.

npx @speclynx/cli validate openapi.yaml

SpecLynx auto-detects the document type and version, then reports every problem with its exact location:

bash 
$ npx @speclynx/cli validate openapi.yaml
openapi.yaml
  3:3-3:9    error  3030501  should always have a 'version'
  7:24-7:26  error  3080500  operationId must be a string

✖ 2 problems (2 errors)

2. Gate your CI with it

The exit code is non-zero when problems reach the failure threshold, so the same command drops straight into a pipeline. Tighten the threshold to fail on warnings too:

npx @speclynx/cli validate openapi.yaml --fail-severity warning

Add --format json for machine-readable output. The validate reference covers every option, check category, and exit code.

3. Pick your surface

The same engine runs everywhere. Choose where you want it:

  • Editor — open a spec in the browser, nothing to install. Editor guide
  • OpenAPI Toolkit — validation, completion, and preview inside VS Code. Toolkit guide
  • ApiDOM — parse and query specs from your own code. Installation guide
